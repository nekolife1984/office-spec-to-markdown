# 変換ルール ― PDF

共通ルール（`conversion-rules.md`）と併せて適用する。

PDFはページレイアウトが固定された形式で、見出し・段落といった論理構造を持たない。
構造は「復元」するものであり、抽出にそのままは現れない。

- **見出し階層の復元**：フォントサイズ・太字・番号付けとしおり（目次）を手がかりに階層を決める。
  抽出のページ区切り（`## ページ N`）は作業用の区切りであり、最終Markdownには原則として残さない（ページ参照が必要な資料では注記として残す）。
- **ヘッダー・フッター・ページ番号の除去**：全ページの同じ位置に繰り返し現れるテキストは本文ではない。
  除去し、除去したことを報告に書く。
- **読み順**：複数段組（2カラム）や図の回り込みがある場合、抽出の並びがそのまま読み順とは限らない。
  ページ描画と照合して並べ替える。
- **表**：検出された表はそのまま使うが、ページをまたぐ表は1つに統合し、各ページで繰り返されるヘッダー行は先頭の1回だけにする。
  罫線のない表は検出漏れがあり得るため、ページ描画で目視確認する。
  結合セルの扱いは共通ルール4に従う。
- **図**：埋め込み画像とベクター描画が対象。
  共通ルール3（drawio.svg既定・難しいものはPNG）を適用する。
  ベクター描画の図はページを描画して該当領域を切り出してから判定する。
  グラフ（チャート）は原則PNG。
- **スキャンPDF**：readerの警告が出たページはOCRが前提。
  OCRなしに変換済みとして出してはいけない。
  OCR結果を使う場合はその旨を報告に書く。
- **リンク・しおり**：内部リンクやしおりは見出し構造の手がかりになる。
  外部リンクはMarkdownのリンクとして保持する。
