# 変換ルール ― Excel（.xlsx）

共通ルール（`conversion-rules.md`）と併せて適用する。

Excel仕様書シートはセル格子上の自由形式レイアウトなので、変換前に各シートを分類する：

| シート種別 | 変換方法 |
|---|---|
| データ表（項目定義・一覧） | 論理的な表ごとにMarkdown表を1つ。結合したヘッダーセルは下／右へ値を伝播させ、すべての行が自分のグループを分かるようにする |
| 画面仕様 | 見出し＋項目表に再構成する。画面キャプチャは画像のまま。画像内の項目番号と表の行が一致すること |
| 文章（概要・説明文） | 散らばったセルを読み順（上→下、左→右）に段落へ統合する。巨大でスカスカな表のまま出さない |
| 図主体（フロー図・構成図） | 図をdrawio.svgに描き直し、テキストでの解説を付けた短いMarkdownセクションから参照する。忠実な描き直しができないほど高密度・精密な場合は、PNG描画を参照し、その理由を書く |
| 表紙・改訂履歴 | 表紙→タイトル＋メタ情報リスト。履歴→単純な表 |

処理の細部：

- **結合セル**：共通ルール4の優先順位に従う。
  基本は値の伝播（グループ分けは全セルへ展開、列にまたがるタイトルは見出し化）。
  見た目が重要な表だけHTML表で `rowspan`/`colspan` を保持する。
- **図形・テキストボックス・吹き出しのテキスト** には本物の仕様文が入っていることが多い。
  すべて抽出し（office-docs-readerが`xl/drawings/*.xml` から行う）、アンカーセル順に並べ、それが注釈しているセクションへ吸収する。
  図形の自動名（「正方形/長方形 15」）を見出しとして残してはいけない。
- **セルコメント** は仕様の注記である。
  抽出し、該当項目の説明へ注記として統合する。
- **非表示のシート・行・列**：報告に列挙する。
  非表示シートは、ユーザーが作業用でないと確認した場合だけ変換する。
- **数式**：キャッシュ値を出力する。
  数式自体が仕様（計算ルール）の場合は、数式を別途抽出し（`openpyxl` の `data_only=False`）、値＋数式で提示する。
- **グラフ** はオブジェクトであり画像ではない。
  Excel/LibreOfficeでPNGに描画する。
  数値が重要な場合は、元データ範囲も表として抽出する。
- **セル内画像**（新しいExcel）は浮動画像のようにはアンカーしない。
  `media/` に抽出されるので、セルのリッチ値メタデータで照合するか、PDF描画と視覚的に照合して配置する。
- **罫線**：罫線は抽出（extract.py のセル値）には現れないため、「罫線で図を描いている箇所」はPDF描画か元ファイルの目視で検出する。
  検出した箇所は共通ルール7に従い、表ではなく図としてdrawio.svg／PNG に変換する。
  表の罫線（通常のデータ表の区切り）は変換対象ではなく、Markdown表では再現しない（構造で代替する）。
- **読み順** は自由形式シートでは曖昧である。
  迷ったらシートをPDFに書き出し、描画されたレイアウトを順序と「どの図形がどの表のものか」の正解として使う。
